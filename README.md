# Voltix POS — downloads

Point of sale, inventory and accounting for retail shops, by **MobiSoft**.
Works offline; syncs to the cloud when online.

## Install

Open the **[latest release](https://github.com/mobeenaslam007/voltix_pos_releases/releases/latest)** and download:

| Computer | File |
| --- | --- |
| **Windows** | `Voltix.POS_x.y.z_x64-setup.exe` |
| **Mac** (Intel or Apple Silicon) | `Voltix.POS_x.y.z_universal.dmg` |

On a Mac, the first time: right-click the app → **Open**, because the app isn't notarized yet.

Sign in with the login MobiSoft gave you. Your shop's data downloads automatically.

## Updates

From v0.1.16 the app updates itself. When a new version is published here, an
**"Update to vX"** button appears in the app's top bar. Click it when it suits you,
not in the middle of a sale. Every update is signed, and the app refuses any file that isn't.
